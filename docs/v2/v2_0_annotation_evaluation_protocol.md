# V2.0 人工标注执行指南

## 一、 标注基本规范
1. **文件格式**：PNG 格式，`512×512` 尺寸，`8-bit 单通道灰度`（PIL mode L）。
2. **像素值**：使用 `0`（不属于）和 `255`（属于）两种值，文件保持严格二值。
3. **标注范围**：限定在 `valid_content`（原图真实内容区域）内，四周黑色 padding 保持为 `0`。
4. **辅助工具**：程序将 Canny/LSD 候选图和差异图放入 `helpers/`。最终 mask 由人工判断和绘制。

---

## 二、 需要标注的四类 Mask（核心任务）

需要标注四个目录下的 mask 文件。前三类（Rigid, Soft, Uncertainty）针对原图，第四类（Failure）针对每个 A2 生成结果。

### 1. Rigid Structure（刚性结构边缘）
**目录：`annotations/rigid_structure/`**
* **是什么**：决定场景几何身份的“硬边缘”和“结构线”。
* **线条要求**：保持细线，普通边缘 1 px，模糊处最多 3 px；线条形态保持为线。
* **要标的**：
  * 建筑：外轮廓、屋顶、塔尖、规则门窗、天际线。
  * 街景：道路边界、建筑立面、透视主线。
  * 山体：极少数决定身份的主山脊。
* **不标的**：
  * 墙面纹理、树叶细边、岩石雪纹。
  * **海浪/云层**：波峰、水花、云层虽然梯度高，通常留空。
  * 天空内部、植被内部。

### 2. Soft Stylization（柔性风格化区域）
**目录：`annotations/soft_stylization/`**
* **是什么**：允许 AI 自由发挥、不承担关键拓扑的大片区域。
* **要标的**：大片填充天空、云层、水面、波浪、水花、草地、植被纹理、雪面、背景材质。
* **边界规则**：Soft 与 Rigid 不重叠；程序自动剔除 Rigid 边缘周边 1 px 的 Soft 标注，Rigid 优先。

### 3. Geometry Failure（几何失败区域）
**目录：`annotations/geometry_failure/`**
* **是什么**：AI（A2 输出）发生的**结构性几何错误**。
* **标注方式**：**每个 A2 seed 单独标一份！** 必须对比原图和对应的 A2 输出。
* **要标的**：
  * 轮廓偏移、断裂、双重轮廓（标细线或窄区域）。
  * 凭空新增的建筑、三角构筑物（标出整个错误结构）。
  * 屋顶、窗格、道路、天际线变形（标受影响区域）。
  * 山体、云层、植被被“建筑化”或变僵硬（标被接管区域）。
* **不标的**：单纯颜色变化、材质变化、合理的笔触变化。

### 4. Uncertainty（不确定区域）
**目录：`annotations/uncertainty/`**
* **是什么**：人工无法可靠判断是否属于“几何失败”的区域。
* **使用范围**：仅用于 Geometry Failure 的判定不确定区；Rigid 和 Soft 的边界问题在对应 mask 中处理。评价时这些像素直接忽略。

---

## 三、 评价独立性

1. Rigid 和 Failure 的 GT 根据原图、对应输出和标注协议独立绘制，不使用 R0 风险图作为绘制依据。
2. `edge_difference` 等脚本生成辅助信息；Failure mask 由人工判定。
3. Canny 的高梯度候选与刚性结构分开判断，树叶、水花等高梯度区域按场景几何作用处理。
4. 没有刚性结构的图像保留全黑 Rigid mask。

---

## 四、 执行流程总结

1. **准备**：运行 `python scripts/build_v2_0_annotation_manifest.py` 生成空 mask 和辅助图。
2. **画图**：打开图像编辑器，参考 `helpers/` 里的辅助图，在 `annotations/` 的四个目录里画 mask。
3. **检查**：确保画的是 0/255 二值图，确保没有画到 padding 上。
4. **完工确认**：全部检查无误后，运行 `python scripts/finalize_v2_0_annotations.py --confirm-reviewed`，程序会自动裁剪 padding、清理 Soft 与 Rigid 的重叠，并验证格式。只有变成 `complete` 状态才算完成。
