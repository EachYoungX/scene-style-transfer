# V1 阶段实验结果汇总

> 本文档是 V1 阶段的统一中文入口，覆盖基线、强度扫描、兼容性诊断、后处理路由、token 表征诊断和 V1.5 因果校正，记录已完成实验及其阶段定位。

## 1. 阶段结论

V1 阶段得到的核心结论是：

> 强风格迁移的失败由内容结构刚性、参考图语义/布局压力以及内容—参考图兼容性共同决定。全局调大风格强度可以获得明显笔触和色调，但会增加参考元素泄漏、局部几何变形、方向漂移和场景重生成。

因此，研究问题已经从“寻找一个合适的全局风格权重”收缩为：

```text
保留全局外观风格；
在危险区域抑制局部参考语义和结构先验；
在可安全迁移的区域允许更强的纹理和笔触。
```

这一目标仍未被当前 V1 方法实现。V1 的价值主要在于建立了失败机制、对照协议和下一阶段的必要性。

## 2. 基线阶段：初始迁移过弱

早期 `debug_*` 基线比较了 `img2img`、`controlnet_canny` 和 `ip_adapter_canny`。总体结果低于有用的 F4“滤镜级风格化”：很多输出只是轻微模糊或调色，参考画风特征不明显。

### `debug_city_architecture`

原始远景构图主题少，与参考图的语义关系弱，难以评价。随后增加 `photo_architecture_basilica` 作为更贴切的建筑案例，但初始三种方法仍主要表现为模糊化，画风迁移不足。

### `debug_forest`

内容图与参考图构图相近，但明暗差异明显。`img2img` 和 `controlnet_canny` 几乎没有学到参考画风；`ip_adapter_canny` 让落叶纹理更明显，并出现极弱的主观调色，但整体仍缺乏强风格相干性。

### `debug_mountain_lake`

由于参考风格抽象，三种方法接近原图，只出现轻微模糊和色调差异。`ip_adapter_canny` 饱和度略高，风格迁移仍然较弱。

### `debug_sea_coast`

内容与参考构图差距大，Hokusai 参考图较扁平抽象。结果偶尔出现皮革质感，但没有稳定的参考画风特征。

### 基线阶段结论

当风格注入仍然弱于可见风格化时，讨论结构风险路由没有意义。必须先建立可见的风格—结构权衡，因此转入强度扫描。

## 3. 强度扫描：风格—结构权衡被明确观察到

主要设置为 `balanced`、`strong_style`、`max_style_weak_structure` 和 `style_only_pressure`。这一轮证明模型能够产生明显风格迁移，但强度增加会同步提高结构损坏和参考语义泄漏。

### 建筑案例

- `balanced` 保留原图最多，只出现少量笔触，阴影和雕花细节有丢失或扭曲。
- `strong_style` 出现清晰风格迁移，建筑整体仍与原图相近，是主观上较好的折中点。
- `max_style_weak_structure` 的笔触和风格相似度很强，主观约 80%，但圆拱形屋顶开始向参考图的哥特式尖顶变化，结构相似度下降到约 70%。
- `style_only_pressure` 风格相似度可达约 90%，暖色调更明显，但建筑朝向向参考图漂移，屋顶和整体结构被重生成，已经更像融合生成的新图而不是迁移结果。

主要失败：`F1` 建筑结构变形、`F2` 方向/布局漂移、`F3` 参考建筑语义泄漏、`F5` 场景部分重生成。

### 森林案例

内容图是两侧整齐排列的深色杉树和直小路，参考图是明亮、杂乱的白桦树林且没有明显路径。

- `balanced` 保留暗色基调，落叶有少量纹理化，但风格弱。
- `strong_style` 色调更接近参考图，画面更鲜艳，但仍偏向原图。
- `max_style_weak_structure` 明显更亮，落叶开始出现色块感，树干出现横向纹理；小路被树木遮挡，结构开始向无路径森林转变。
- `style_only_pressure` 进一步出现原图没有的苔藓和树干结构，小路消失，整体接近参考语义下的重新生成。

主要失败：`F2` 路径消失或布局漂移、`F3` 白桦/密林语义泄漏、`F5` 场景重生成；低强度设置仍存在 `F4` 风格不足。

### 强度扫描的阶段性结论

最佳研究目标位于 `strong_style` 与 `max_style_weak_structure` 之间：让高风险结构保持清晰，同时允许低风险区域获得更强的局部风格。建筑轮廓、拱顶、道路边界和整体朝向应受到保护；森林小路和树木排列应受到保护，而落叶、树皮等表面纹理可以更自由地迁移。

## 4. V0 风险图和全局路由：可解释，区域控制能力有限

初版风险图曾过度响应高对比边缘：

- `debug_forest` 把路径尽头的高亮天空选得比小路更亮；
- `debug_mountain_lake` 偏向信息密集的前景/远景边缘，空间通道覆盖不足。

加入路径、消失点、地面交界和布局边界先验后，风险图更接近预期：森林的小路底部和地面交界风险最高，主树干和路径两侧边界为中低风险；山水图中轮廓和布局边界较高风险，湖水、山体、天空和连续树林较低风险。

这一结果支持“结构风险需要按场景部位拆分”的叙事：建筑应拆成轮廓/关键几何线、平坦材质、阴影与低纹理内部，分别记录其风险。

但 V0 的全局参数路由只是在已有强度曲线上移动：默认版本介于 `balanced` 与 `strong_style` 之间，`push` 版本在建筑上接近 `strong_style`，在森林上只略微偏向参考色调。它仍停留在全局强度调节，定位为诊断性 baseline。

## 5. Two-pass 后处理：自然场景有局部修复能力，刚性建筑会冲突

后处理形式为：

```text
output = alpha * safe_candidate + (1 - alpha) * strong_candidate
```

当前风险图过于模糊且覆盖面积不足时，输出自然偏向 `max_style_weak_structure`。扩大阈值区域并膨胀 mask 后，森林中可以恢复小路、远处缝隙、地面通道和部分树干深度，说明自然场景的强/安全候选仍共享部分空间拓扑。

建筑则不同：安全候选保留圆拱，强候选已经生成尖顶。RGB 混合只能叠加两套边界，产生双轮廓、粘连和模糊结构。two-pass 定位为诊断性 baseline。

得到的分类是：

| 场景区域 | 后验融合表现 | 方法含义 |
|---|---|---|
| 天空、水面、云雾 | 通常较可融合 | 可允许较强外观和纹理迁移 |
| 森林、草地、山体 | 有条件地恢复局部可读性 | 适合软保护与局部降权 |
| 道路、桥梁、城市街景 | 不稳定 | 需要更强的几何约束 |
| 建筑、教堂、地标 | 容易双边界和结构冲突 | 必须在扩散过程或 latent/attention 空间保护几何 |

## 6. 兼容性诊断：内容刚性与配对关系共同决定结果

V1 将配对分为四组：

| 组别 | 关系 | 典型风险 |
|---|---|---|
| `G1` | 语义与布局都相近 | 主要是局部几何变形，风格可稳定增强 |
| `G2` | 语义相近但方向不一致 | 波向、主流线等方向压力导致漂移 |
| `G3` | 语义相近但空间层级不一致 | 路径、深度通道、前景/远景被参考图替换 |
| `G4` | 语义和布局都不匹配 | 参考对象泄漏和场景重生成最严重 |

强风格失效可概括为：

```text
P_regen ∝ style_strength * reference_semantic_pressure * (1 - compatibility)
P_distort ∝ style_strength * content_rigidity * (1 - local_transferability)
```

因此，后续方法至少需要同时考虑内容刚性 `R`、参考语义/布局压力 `P` 和内容—参考兼容性 `M`。

## 7. raw / pooled / texture-bank 诊断

### `raw`

风格、颜色和纹理融合最强，但容易把参考对象、方向、构图骨架和签名/Fuji 等局部元素带入内容图。它适合作为强风格上限，不适合作为安全默认值。

### `pooled`

结构最安全，内容身份保留较好，但局部笔触、材质和细粒度风格明显减弱。它适合作为结构安全对照，风格强度较低。

### `texture_bank` 与 `global_plus_texture`

这两个变体完全失效，输出混乱，缺乏正常图像效果。问题对应当前纹理库的组织方式：对 IP-Adapter Plus 来说，拼接的纹理 patch 仍可能被解释为独立的小场景或对象 token，导致错误的语义条件。该路线已停止作为主方法，仅保留为失败诊断。

### 诊断结论

参考图需要结合全局风格、局部纹理和语义对象关系处理。当前 Plus 投影器仍可能将局部 patch 当作语义对象。后续转向控制注入位置和时间。

## 8. V1 layer/time injection：当前主线

V1 实现了 U-Net 层级和去噪时间调度：

| 变体 | 作用 |
|---|---|
| `A0_raw_all` | 全层 raw 注入基线 |
| `A1_lowres_only` | 只使用 Down/Mid 低分辨率路径 |
| `A2_highres_only` | 只使用 Up 高分辨率路径 |
| `A3_highres_plus_weak_mid` | 强高分辨率注入并保留弱 Mid |
| `T1_late_style` | 前期关闭、后期打开风格注入 |
| `T2_gradual_style` | 随时间逐步增加风格注入 |
| `T3_late_highres` | 后期强调高分辨率注入 |

这一轮的研究问题是：A2/A3/T3 的风格增益是否来自注入路径，而非总 residual 预算差异。V1.5 已进一步完成 residual matching、多 seed 和 reference-only purification 对照。

## 9. V1.5 冻结结果

详细结果见 [V1.5 结果汇总](v1_5_results.md)。核心结论：

- `A2_highres_only` 相对 residual-matched A0 仍有独立的路径风格增益；
- 高分辨率参考注入会重复带来局部建筑几何风险；
- reference-only masking 与 SVD purification 没有在多配对、多 seed 下形成稳定几何安全优势；
- 本阶段停止继续堆叠 reference-only purification 变体；
- V2 已完成几何风险、局部门控、区域分配和全局强度响应验证，当前进入生成前 pair feature 分析。

## 10. 结论边界与后续工作

### 已证实

- 强风格注入确实提高笔触、色调和局部纹理迁移；
- 风格增强同时提高 F1/F2/F3/F5 风险；
- 内容—参考兼容性会改变失败机制；
- two-pass 对部分自然软结构有局部修复能力，但对建筑几何冲突无效；
- `A2_highres_only` 具有可重复观察的路径风格优势。

### 待完成工作

- 几何失败预测指标仍在建立；
- 空间 residual gate 对最终建筑几何的锁定能力仍需验证；
- 跨配对稳定工作的统一规则 router 尚未形成；
- 局部 token 抑制对全局风格与内容结构的联合影响仍需验证。

### 阶段边界

- V1 完成了问题诊断，结构保持方法留给后续阶段；
- 风险图定位为启发式诊断信号，不承担语义分割任务；
- two-pass 定位为后处理对照；
- `texture_bank` 的失败对应当前 Plus patch 组织方式，局部纹理注入的其他组织方式仍可单独评估。
