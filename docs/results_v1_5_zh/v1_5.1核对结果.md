## 本次修正

原日志回调在 step-end 更新元数据，导致 residual 日志首步 timestep 为 `None`，后续 timestep 错位。针对 `diffusers 0.35.2` 仅支持 step-end callback 的实际情况，运行脚本现在预先读取 scheduler timesteps，并在每步结束时为下一步写入正确的 timestep。

同时，V1.5 runner 不再在 case prompt 后追加 `strong reference style, preserve content layout`，改为直接使用 manifest 中的中性内容描述，避免 prompt 同时承担风格注入和失败抑制。

修正后的 representative pilot 已完整生成：

- `Demuth × church`：A0 raw、A2、residual-matched A0；
- `Kulhanek × photo_snow_winter`：A0 raw、A2、residual-matched A0；
- 均为 30 inference steps、seed 42，实际 img2img denoising 记录为 22 steps；
- 三类日志均无 `None` timestep，step 范围为 0--21。

## 修正 pilot 人工判断

### Demuth × church

`A0_raw_all` 复制了参考图右下角白色抽象几何和右上标志性铁架塔。草地破碎，几何边界被破坏，并出现异常参考颜色入侵。它对参考图天空中的抽象直线、圆弧和深浅色块迁移非常强，但除教堂主体外的背景保持较差。

`A2_highres_only` 在保持教堂主体结构的同时，比 matched A0 带来明显更强的颜色、笔触和材质迁移。天空仍能迁移抽象直线、圆弧和色块，但整体不如 A0 raw 那样接近参考原画风。A2 只出现少量局部参考对象、硬边、轮廓或几何错误；其中 matched A0 背景的模糊三角结构，在 A2 中被放大成了建筑形态。

### Kulhanek × photo_snow_winter

`A0_raw_all` 将山峰错误生成到原图建筑中，造成融合错乱并破坏原图边界，但笔触鲜明，参考图画风相似度高。

`A2_highres_only` 的错误少于 A0 raw，但多于 matched A0；同时比 matched A0 具有更强的风格迁移效果。

### Pilot 结论

这两组结果进一步确认：A0 raw 的强风格来自明显的参考几何和颜色接管，不能作为安全方案。A2 相对 matched A0 的优势是真实的风格增强，同时仍存在少量路径相关的局部几何风险。matched A0 在这两组中继续表现为内容和结构优先的保守方案。

## 尚未由 v1_5.1 结果解决的项目

- masking / SVD purification 尚未作为竞争机制运行，不能据此判断 reference-only 纯化是否足够。
- 结构/泄漏 heatmap 仍需人工标签或结构指标支撑，residual heatmap 不能单独代表结构风险。
- 当前结果足以支持 A0 与 A2 的风格—结构 tradeoff，但不等同于完成全部后续方法比较。
