## 结论摘要

- `A0_raw_all` 风格压力强，但容易发生参考对象、硬几何和构图片段接管。
- `A0_all_residual_energy_matched` 更保守，内容身份和原图细节保留较好，风格迁移较弱。
- `A2_highres_only` 风格笔触和颜色迁移更强，但更容易损失原图细节并引入错误结构。
- 同一内容图和参考图下，A0 与 A2 是内容保持和风格强度之间的取舍，不是简单的好坏关系。
- 语义对应不能保证几何安全；`Demuth × church` 仍可能出现参考几何接管。
- 当前雪景内容使用 `photo_snow_winter.jpg`；`photo_seregei_city.jpg` 是另一组城市街景样本，不属于当前雪景命名。
