# 人工评价说明

## 评价对象

每个 `case + seed` 组内并排比较：

- `A0_raw_all`
- `A0_all_residual_energy_matched`
- `A2_highres_only`

评分数字表达同组内的相对差异，不表达跨样本或跨场景的绝对质量。

## 指标含义

- 内容身份保持：主要场景、主体和原图语义是否保留。
- 结构保持：建筑、道路、山脊、天际线、主体轮廓和拓扑是否稳定。
- 风格强度：参考图的颜色、笔触、材质和边缘语言迁移程度。
- 参考泄漏：参考对象、局部轮廓、硬平面或构图片段是否被复制。
- 局部几何风险：是否出现错误硬边、区域混合、轮廓扭曲或结构接管。

## 阅读优先级

先看内容身份、结构保持、参考泄漏和局部几何风险，再看风格强度。风格更强不等于结果更好；A2 的判断必须同时考虑它带来的结构风险。

每个非零泄漏或几何风险应结合区域说明阅读，例如屋顶轮廓、山脊进入建筑、波浪边缘进入道路等。
